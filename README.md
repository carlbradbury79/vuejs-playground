# Pokémon VueJS Playground

A simple Pokémon-themed VueJS application designed for learning Vue.js concepts.

## 🚀 Getting Started

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```

Then open your browser to `http://localhost:5173`

### Build for Production
```bash
npm run build
```

## 📚 What's Included

- **Two Pages**: Home and Pokémon List
- **Header Component**: Navigation across pages
- **Footer Component**: Shared footer information
- **Vue Router**: Client-side routing between pages
- **Learning Comments**: Throughout the code to guide your learning

## 🎯 Learning Objectives

This project is set up to help you learn:

1. **Vue Components** - Reusable UI pieces (Header, Footer)
2. **Vue Router** - Navigation between pages
3. **Component Structure** - Template, Script, Style sections
4. **Props & Data** - Component state management
5. **Lifecycle Hooks** - When to fetch data (see comments)
6. **API Integration** - Ready for PokéAPI integration (see comments)

## 🔨 Suggested Next Steps

1. **Add API Integration**: Fetch real Pokémon data from [PokéAPI](https://pokeapi.co/)
2. **Create Detail Page**: Add a route for individual Pokémon details
3. **Add Search/Filter**: Implement search and type filtering
4. **State Management**: Add Vuex or Pinia for global state
5. **Local Storage**: Save favorites to browser storage
6. **Styling**: Customize the design with your own theme
